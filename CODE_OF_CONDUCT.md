# Code of conduct

Contributors and maintainers are expected to communicate respectfully, focus criticism on the work, welcome good-faith questions, and avoid harassment, discrimination, threats, or disclosure of another person's private information.

Project discussions must not contain credentials, proprietary datasets, private schemas, production query results, customer information, or security evidence that would create additional exposure.

Report conduct or security concerns privately to the repository owner. Maintainers may edit or remove harmful content and restrict participation when necessary to protect the community and its users.
